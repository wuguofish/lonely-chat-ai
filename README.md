# lonely-chat-ai

「寂寞的人坐著與AI聊天」——阿童和 AI 夥伴一起做的東西。

- 線上：https://wuguofish.github.io/lonely-chat-ai/
- 技術：Vue 3、Vite、Tailwind CSS 4
- 字體：俐方體 11 號（標題）、台北黑體（內文，`@vp-tw/cjk-web-fonts-taipei-sans-tc`）、芫荽（詩句，Google Fonts）
- 配色：薄荷巧克力，跟系統明暗設定走

## 開發

```bash
npm install
npm run dev
npm run build
```

推到 `main` 會由 GitHub Actions 自動部署到 GitHub Pages。卡片內容都在 `src/data/projects.js`。
